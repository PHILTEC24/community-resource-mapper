#  Local Community Resource Mapper

A real-time web application designed to help citizens, emergency services, and community workers quickly locate and map vital infrastructure such as health centers, water points, police posts, and public schools.

---

## ✨ Features
- **Interactive Map Engine:** Powered by Leaflet.js and OpenStreetMap with custom UI tiles.
- **Real-Time Cloud Database:** Instant updates using Google Firebase Firestore (no server lag).
- **Coordinate Picker:** Click anywhere on the map to automatically capture exact latitude and longitude.
- **Fully Responsive:** Optimized for desktop screens and mobile phones with a smooth sliding drawer layout.

---

## 🛠 Tech Stack
- **Frontend:** HTML5, CSS3, JavaScript (ES6 Modules)
- **Mapping Library:** Leaflet.js
- **Cloud Backend & Database:** Google Firebase Firestore
- **Hosting:** GitHub Pages
